## 確認結果（プロのエンジニアとしてのチェック）

### ① 技術的な正確さ（主なもの）

| ネタ | 確認した事実 |
|---|---|
| commit -am | git commit -a は、追跡中のファイルの変更だけを含みます。新しいファイルは含みません |
| featureとfeature/login | Git では、feature というブランチがあると feature/〇〇 は作れません |
| GitHub Pages | 非公開リポジトリから公開したページでも、ページ自体は公開されます（Enterprise の限定公開を除く） |
| 60日で止まるActions | 公開リポジトリで60日間更新がないと、スケジュール実行のワークフローは自動で無効になります |
| fetch-depth 1 | actions/checkout は初期値で最新1コミットだけを取るため、タグが必要な処理が失敗します |
| INSERT IGNORE / REPLACE INTO | INSERT IGNORE はエラーを警告に変えて捨てます。REPLACE INTO は削除してから挿入するので、自動採番の ID が変わることがあります |
| 減らないDBの容量 | MySQL の InnoDB は、DELETE しても既存のファイルを小さくしません |
| 朝一番のgone away | MySQL の wait_timeout は、初期値が8時間です |
| KEYS * | Redis の KEYS は全キーをなめるので、その間ほかの処理が止まります |
| GETとHEADだけ | CloudFront の許可メソッドは、初期値が GET と HEAD です |
| SPFが2行 | SPF レコードが2つあると、エラー（permerror）になります |
| 126年 | JavaScript の getYear() は、1900を引いた値を返します |
| map(parseInt) | map は2番目の引数に添字を渡すため、parseInt の基数として使われ、NaN になります |
| MySQLの|| | MySQL では、初期設定で || は論理和です（文字列の連結は CONCAT を使います） |
| \dと全角数字 | Python 3 の \d は、全角数字などの Unicode の数字にも一致します |
| 改行は2文字 | フォームを送ると、改行は CR+LF の2文字に変わります |
| utcnowの警告 | datetime.utcnow() は、Python 3.12 で非推奨になりました |
| 7日で起きるDB | RDS は停止しても、7日たつと自動で起動します |
| httpではカメラが使えない | ブラウザのカメラは、HTTPS（または localhost）でないと使えません |
| #スピル! / XLOOKUP | 結果を広げる先のセルが空いていないと #スピル! になります。XLOOKUP は古い Excel では #NAME? になります |
| Googleの15GB | Google アカウントの無料15GBは、Gmail・Drive・フォトで共有です |
| 93日のごみ箱 | SharePoint のごみ箱は、93日で完全に削除されます |
| 急に上がった開封率 | iPhone のメールの「プライバシー保護」は画像を先に読み込むため、開封したことになります |
| Webサイトを包んだだけのアプリ | App Store の審査では、Web サイトを表示するだけのアプリは最低限の機能に満たないとして却下されます |
| 101人目 | Zoom の Pro プランは、初期で参加者100人までです |

### ② 現場で起こり得るか

- 150個すべて、実際の問い合わせ、障害、診断の指摘、運用の事故でよく見る形にしてあります。
- 作る途中で、次のものを直しました。

| 直したもの | 理由 |
|---|---|
| 後から.gitignore | 過去のストックの「.gitignore」と、オチ（追跡済みのファイル）が同じでした。「fetch-depth 1」に差し替えました |
| 本番にない環境変数 | 過去のストックの「環境変数」と近い内容でした。「Cookieのパス」に差し替えました |
| Rubyの0 | 「0もtrue扱い」は、true と == になると誤解されます。「0も真」に直しました |
| Secure属性（不採用） | Chrome は localhost を安全な場所として扱うため、「ローカルで Cookie が送られない」は環境によって起きません。外しました |
| 季節感のある請求書（不採用） | 技術の話が薄いので外しました |

## 伸びやすそうな10選

1. **10年止めていないサーバ**：「回ってるから、動いてるんだよ」の一言が、インフラ担当の心に刺さります。
2. **必ず当たる抽選**：「…公平とは」の切り返しで、理不尽さが一瞬で伝わります。
3. **カラス**：「報告書に、カラスと書くんだね」は、実話っぽさと笑いの両方があります。
4. **testさん**：「本物のtestさんがいたね」の短いオチが強いです。
5. **黄色が済み**：「色は、データじゃないんです」で、現場のExcel文化への共感が集まります。
6. **会議に参加するスピーカー**：「ずっと聞いてたね」の一言が、ちょっと怖くて笑えます。
7. **1台で止めない**：「でも止めないで」に「…2台にしましょう」と返すやり取りが、SEの日常そのものです。
8. **コメントの悪口**：「…お客様が読んでます」で、どのエンジニアもヒヤッとします。
9. **甘いコーヒー**：「砂糖入りは、あとで固まります」は、一般の人にも伝わる実用的なオチです。
10. **ラベルのないケーブル**：「抜いてみて、誰が怒るかだね」が、現場のリアルです。
