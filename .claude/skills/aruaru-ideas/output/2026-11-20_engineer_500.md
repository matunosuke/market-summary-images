## 確認結果（プロのエンジニアとしてのチェック）

### ① 技術的な正確さ（主なもの）

| ネタ | 確認した事実 |
|---|---|
| divergent branches | Git 2.27 以降、ローカルとリモートの両方にコミットがあると、マージかリベースかの設定を求められます（新しい版では止まります） |
| distutils | Python 3.12 で標準ライブラリから削除されました |
| ERR_OSSL | Node.js 17 以降（OpenSSL 3）では、古い webpack 4 がこのエラーで止まります |
| Java 18の文字コード | Java 18（JEP 400）から、標準の文字コードが UTF-8 になりました |
| CentOS 7 | 2024年6月30日でサポートが終わり、リポジトリは保管用の場所に移されました |
| 番号の再利用 | MySQL 5.7 の InnoDB は、再起動すると連番が「今ある最大値＋1」に戻ります（8.0 で修正） |
| バケット名test | S3 のバケット名は、全世界で重複できません |
| CPUクレジット | t2 は CPU クレジットを使い切ると、性能が絞られます |
| 同じアドレス帯 | アドレス帯が重なる VPC 同士は、ピアリングで接続できません |
| 停止と終了 | EC2 の「終了（Terminate）」はインスタンスの削除です |
| 30年は1930年 | Excel は2桁の年を、00〜29 なら2000年代、30〜99 なら1900年代と解釈します |
| PSTの50GB | Outlook のデータファイル（PST）は、初期設定で50GBが上限です |

### ② 現場で起こり得るか

- 500個すべて、実際の問い合わせ、障害報告、脆弱性診断の指摘、運用の事故でよく見る形にしてあります。
- 作る途中で、次のものを直しました。

| 直したもの | 理由 |
|---|---|
| divergent branches | 最初は「pull すると勝手にマージコミットができる」にしていました。新しい Git は止まって設定を求めるので、そちらに直しました |
| java.awt.List | java.awt.List にも add はあるので、「add がない」は不正確です。List<String> がエラーになる形に直しました |
| 500% | 書式が%のセルに5と入れると、Excel は5%にします。「入力済みの5を%表示にしたら500%」に直しました |
| nginx -t | 設定が壊れていても、reload なら古い設定で動き続けます。止まるのは restart なので、そちらに直しました |
| WAFの誤検知 | 「select」の1語だけでは、ふつう WAF は反応しません。HTML のタグを含む質問に変えました |
| 経度が先 | 「全部南極」は座標として成り立たないので外し、GeoJSON の順番の話にしました |
| 0.0.0.0/0、noindexの消し忘れ、2年前のスナップショット | 過去のストック（0.0.0.0、noindex、スナップショット）とオチが重なるため、「停止と終了」「画像の直リンク」「物理の2倍」に差し替えました |
| 503とRetry-After ほか2件 | オチがない、または今はほとんど起きない形だったので、「Webhookの署名」などに差し替えました |
| 拡大禁止（不採用） | iPhone の Safari は、拡大禁止の設定を無視するので外しました |
| 413（不採用）、k8sのSecret（不採用） | 過去のストック（アップロード上限、Base64）と重なるので外しました |

## 伸びやすそうな10選

1. **机の下のサーバ**：「掃除機でも止まりますね」が、中小企業の現場の人に刺さります。
2. **クラウドだから落ちない**：「…大手も落ちます」の切り返しが短くて強いです。
3. **パスワードを教えて**：「私たちも知らないんです」で、一般の人も仕組みがわかります。
4. **社外に出さないクラウド**：「クラウドは社外です」の一言で、矛盾した要望がはっきりします。
5. **本人が不審**：出張したエンジニアなら誰でも経験があり、オチも笑えます。
6. **9999年12月31日**：「永遠の社員だね」の一言が強いです。
7. **8割が北海道**：データ分析をする人なら、一度は見た光景です。
8. **点滅するランプ**：「はい、元気です」というやさしいオチで、一般の人にも伝わります。
9. **Password1!**：「真っ先に試されるやつです」で、セキュリティ担当がうなずきます。
10. **検索1位**：「新しいから、です」の切り返しで、Web 制作の現場の人に刺さります。
