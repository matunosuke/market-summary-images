# エンジニアあるある（会話形式）ストック

1行1ネタ。`タイトル：セリフ / セリフ / …`。（ ）は心の声・ト書き。

## 基本
- いい感じに：顧客「いい感じにしてください」/ SE「いい感じとは…」/ 顧客「見ればわかります」
- 進捗：上司「進捗どう？」/ SE「9割できてます」/（残り1割にあと9割の時間がかかる）
- 全部動かない：顧客「動かないんですけど」/ SE「どの画面ですか？」/ 顧客「全部です」/（ログインしてなかった）
- 僕の環境では：PM「本番で動かないって」/ SE「僕の環境では動きます」/ PM「じゃあ君のPCを本番にしようか」
- 見積もり：営業「何日でできる？」/ SE「2週間です」/ 営業「お客様には3日と伝えてあります」
- 現行システム：顧客「今の運用をシステム化したい」/ SE「今はどう管理？」/ 顧客「Excelのマクロです。作った人はもういません」
- AIで：顧客「AIで何とかなりませんか？」/ SE「何をですか？」/ 顧客「全部です」
- このコード誰？：先輩「このひどいコード書いたの誰？」/ SE「…」/（git blameを見たら自分）
- 障害対応：顧客「原因は？」/ SE「調査中です」/ 顧客「いつわかりますか？」/ SE「それも調査中です」
- 仕様書：新人「仕様書はありますか？」/ 先輩「コードが仕様書だよ」
