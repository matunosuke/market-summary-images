# 制度への不満（勉三系・物申す系）ストック

数字は必ず最新の公式情報で確認してから使うこと。以下は2026年10〜11月時点で確認済みの事実。

## 税・社会保険料（30）
4〜6月の残業で社会保険料が1年上がる（定時決定、9月〜翌8月） / 一番大きい控除は社会保険料 / ボーナスからも社会保険料 / 40歳から介護保険 /
通勤手当にも社会保険料（所得税は非課税、社保は算入） / 会社負担分も実質は自分の給料 / 子ども・子育て支援金（2026年4月〜、医療保険料に上乗せ） / 窓口でさらに3割 /
食料品1%でも社会保険料は変わらない / テイクアウト1%・店内10%（2027年4月〜2年間の予定） / 消費税は社会保障のためなのに社保も上がる / ガソリン税にも消費税（旧暫定税率は2025年末廃止） /
退職翌年の住民税 / 副業20万円以下でも住民税申告は必要 / 所得税の壁は160万円、社保の壁は残る / 16歳未満は扶養控除なし（2011年廃止） / 森林環境税 年1,000円（2024年度〜） / 源泉徴収で負担に気づきにくい /
国民年金40年・受給65歳 / マクロ経済スライド / 年金からも税と保険料 / 退職後の国保が高い / 額面が上がっても手取り変わらず / 実質賃金4年連続マイナス（2025年 −1.3%） /
国民負担率 約46%（2026年度見通し45.7%、財務省） / 年収の壁で働き控え / 再エネ賦課金 / 13年超で自動車税 約15%重課 / インボイスで手取り減 / ふるさと納税のポイント禁止（2025年10月〜）

## 税・社保以外（30）
役所は平日昼だけ / 住所変更を1件ずつ / 結婚で名義変更が何十件 / 「ハンコ不要」なのにハンコ / 年末調整の書類が毎年同じ / 免許更新の講習 /
紹介状なしの大病院は初診7,000円以上（2022年10月〜） / マイナ保険証 / 有給の理由を聞かれる（法的義務なし） / 退職は法律上2週間前でOK（民法627条） /
定年後再雇用で給料が下がる / 転勤の辞令 / 経費精算の紙とハンコ / 男性育休が取れない空気 / 新卒一括採用 /
保証人がいるのに保証会社 / 更新料 / 原状回復費 / 銀行窓口は15時 / ATM手数料 / 郵便の土曜配達終了（2021年10月）と値上げ（2024年10月、はがき85円・封書110円） /
